Overview

WSSL is a WebSocket server library written in C. The build produces two artifacts in out/: the static library libwssl.a and the single public header wssl.h. Applications in examples/ link against those two files.

  • Single-threaded, epoll based event loop.
  • Plain TCP and TLS servers in the same process (OpenSSL).
  • Callback driven: connect, header, text, binary, ping, pong, close, tick, disconnect.
  • Per-connection extra pointer plus one global extra pointer for application state.

Public header is self-contained: one include of wssl.h is enough. Link with -lssl -lcrypto.

Build and link

make # builds out/libwssl.a, out/wssl.h and examples make clean # removes out/, objects and example binaries

Every example links the same way:

cc -std=c99 -O3 -Werror -Iout -o app.e app.c out/libwssl.a -lssl -lcrypto

Include path must point at out/ so that #include "wssl.h" resolves to the generated single header, not to include/ internals.

Whoever uses wssl.h must define _POSIX_C_SOURCE on their own, before any system header; recommended value is 200809L, the one the library itself uses. Without it the monotonic clock the timeout machinery runs on is not visible.

Quick start (echo)

Minimal echo server, same shape as examples/echo.c:

#include "wssl.h" wssl_callback_result_e on_receive_text_frame(wssl_client_t* client, char* data, wssl_size_t data_size) { wssl_client_send_string(client, &WSSL_MAKE_STRING(data, data_size)); return WSSL_CALLBACK_RESULT_OK; } int main(void) { WSSL_DECLARE(wssl); wssl_set_on_receive_text_frame_callback(&wssl, &on_receive_text_frame); wssl_server_configuration_t config = WSSL_SERVER_CONFIGURATION_IPV6_DUAL_STACK; wssl_server_configuration_set_port(&config, 5001); WSSL_TRY_CALL(wssl_server_add(&wssl, &config)); WSSL_TRY_CALL(wssl_loop_init_signals()); WSSL_TRY_CALL(wssl_loop(&wssl)); WSSL_TRY_CALL(wssl_clean(&wssl)); return 0; }

Steps: declare the wssl_t instance, register callbacks, add at least one server, install signal handling, run the loop, clean up.

Event loop and callbacks

wssl_loop() runs until a signal stops it. The core concept is one loop around one epoll instance, single-threaded: every socket the library owns, listen sockets and client connections alike, is nonblocking (O_NONBLOCK), so the loop never stalls on any single client. Each pass blocks in epoll_wait up to sleep_in_mseconds, dispatches readable sockets to receive and writable ones to send, checks per-client timeouts, then runs on_tick and deletes the clients marked for disconnecting. Callbacks never run in parallel with each other, so no locking is needed in application code.

For each connection the library calls, in order:

  1. on_connect_callback - new TCP/TLS connection accepted.
  2. on_receive_header_callback - HTTP upgrade header parsed; inspect client->header here (URI, fields).
  3. on_start_receiving_frames_callback - handshake done, WebSocket frames follow.
  4. on_receive_text_frame_callback / on_receive_binary_frame_callback / on_receive_ping_frame_callback / on_receive_pong_frame_callback / on_receive_close_frame_callback - one per frame.
  5. on_disconnect_callback - connection is going away, with a wssl_client_disconnect_reason_e.

In parallel, on_tick_callback fires every sleep_in_mseconds when the loop is idle. Return true to keep looping, false to stop. Any frame callback returns WSSL_CALLBACK_RESULT_OK to continue, WSSL_CALLBACK_RESULT_DISCONNECT for a clean disconnect, or WSSL_CALLBACK_RESULT_ERROR for an error disconnect.

Servers and TLS

Start from one of the ready-made configuration values, then override fields:

WSSL_SERVER_CONFIGURATION_DEFAULT WSSL_SERVER_CONFIGURATION_IPV4 WSSL_SERVER_CONFIGURATION_IPV6 WSSL_SERVER_CONFIGURATION_IPV6_DUAL_STACK WSSL_SERVER_CONFIGURATION_IPV4_SSL WSSL_SERVER_CONFIGURATION_IPV6_SSL WSSL_SERVER_CONFIGURATION_IPV6_DUAL_STACK_SSL

Set address and port with wssl_server_configuration_set_ip() / wssl_server_configuration_set_port(), then attach with wssl_server_add(). One wssl_t can host several servers (for example plain + TLS side by side).

For TLS either start from an *_SSL preset and call wssl_server_configuration_set_certificate_files(), or call wssl_server_configuration_enable_ssl() with certificate and private key paths. wssl_server_enable_ssl() applies TLS to an already added server.

Sending data

Three send functions cover the common cases. All queue a frame on the client output queue; use them from inside callbacks or from on_tick / for_each iterations:

wssl_client_send_text(client, "hello"); // NUL-terminated C string wssl_client_send_string(client, &WSSL_MAKE_STRING(data, len)); // pointer + length, may be binary-safe wssl_client_send_binary(client, octets, octet_count); // raw octets

To reach every connected WebSocket client, iterate with wssl_for_each_client_in_frame_processing_call() (see examples/chat.c and examples/time.c). To drop a client, call wssl_client_mark_for_disconnecting() instead of closing the socket yourself.

Example: echo examples/echo.c

Sends every text frame straight back to its sender. Default port 5001.

wssl_callback_result_e on_receive_text_frame(wssl_client_t* client, char* data, wssl_size_t data_size) { wssl_client_send_string(client, &WSSL_MAKE_STRING(data, data_size)); return WSSL_CALLBACK_RESULT_OK; }

The callback wraps the received payload in WSSL_MAKE_STRING (pointer plus length, no copy, no NUL terminator assumed) and queues it back on the same client. Returning OK keeps the connection open; the send result is left unchecked in this minimal example.

WSSL_DECLARE(wssl); wssl_set_on_receive_text_frame_callback(&wssl, &on_receive_text_frame);

Only one callback is registered, so every other event uses the default (do nothing, stay connected).

switch (arguments_count) { case 1: // WSSL_SERVER_CONFIGURATION_IPV6_DUAL_STACK, port 5001, wssl_server_add case 2: // servers_read_configurations(argv[1], servers) + wssl_server_add per entry default: // usage error }

With no arguments it serves the dual-stack wildcard address on port 5001. With a file argument it serves every address listed in that file instead. Then the standard tail: wssl_loop_init_signals(), wssl_loop(), wssl_clean().

Example: time examples/time.c

Pushes the current epoch time to all connected clients twice per second. Default port 5002.

wssl_callback_result_e for_client(wssl_client_t* client, void* local_extra_data) { char output[OUTPUT_SIZE]; // OUTPUT_SIZE = 64 snprintf(output, OUTPUT_SIZE, "t=%ld", (long)time(NULL)); wssl_client_send_text(client, output); return WSSL_CALLBACK_RESULT_OK; } bool on_tick(wssl_t* wssl) { wssl_for_each_client_in_frame_processing_call(wssl, &for_client, NULL); return true; }

Each tick formats one t=<seconds> line per client and sends it as a text frame. for_each visits only clients that finished the handshake. Returning true from on_tick keeps the loop running.

wssl_set_sleep_in_mseconds(&wssl, 500); wssl_set_on_tick_callback(&wssl, &on_tick);

No frame callbacks are registered: the server never reacts to inbound messages, it only pushes on the 500 ms tick. Server setup and shutdown are the same shape as echo.

Example: chat examples/chat.c

Broadcast where the raw request URI is used as the room label and the numeric connection id stands in for a nickname. There are no nicknames in this protocol: what you see as room:suffix is literally the URI the client connected with plus its auto-incremented id.suffix. Default port 5003. Three callbacks are registered: start-of-frames, text frame, disconnect.

wssl_callback_result_e for_client(wssl_client_t* client, void* local_extra_data) { wssl_client_send_text(client, (char*)local_extra_data); return WSSL_CALLBACK_RESULT_OK; }

Shared fan-out helper: sends the same preformatted line to one client. Every broadcast builds the line once, then for_each delivers it to all clients in frame processing.

wssl_callback_result_e on_start_receiving_frames(wssl_client_t* client) { snprintf(output, OUTPUT_SIZE, "%s:%" WSSL_PRINT_ID_SUFFIX " = JOIN", client->header.uri.data, client->id.suffix); wssl_for_each_client_in_frame_processing_call( wssl_client_get_wssl(client), &for_client, (void*)output); return WSSL_CALLBACK_RESULT_OK; }

When the handshake completes, the newcomer is announced as room:suffix = JOIN, using the raw header.uri.data string (path and query as received, unparsed) and the auto-incremented id.suffix assigned at accept time. Note wssl_client_get_wssl(client) reaching the root instance from inside a client callback.

wssl_callback_result_e on_receive_text_frame(wssl_client_t* client, char* data, wssl_size_t data_size) { snprintf(output, OUTPUT_SIZE, "%s:%" WSSL_PRINT_ID_SUFFIX " - %s", ...); // same for_each broadcast }

Every message is rebroadcast as room:suffix - text to everyone, sender included, with the same raw URI and numeric suffix; the payload is pasted in as received. There is no per-room filtering: all connected clients get everything, whatever URI each of them used.

void on_disconnect(wssl_client_t* client, wssl_client_disconnect_reason_e disconnect_reason) { if (wssl_client_disconnect_reason_is_not_error(disconnect_reason)) { // broadcast "room:suffix = LEAVE" } }

LEAVE goes out only on clean exits (is_not_error covers NONE, DISCONNECTED, CLOSED, REQUESTED, STOPED); error drops stay silent. on_disconnect returns void, unlike the frame callbacks.

Example: dump examples/dump.c

Lifecycle observer: registers all ten callbacks and prints every event with wssl_client_print(). Plain port 6001, or TLS port 6011 when started with certificate and key arguments.

wssl_callback_result_e on_receive_header(wssl_client_t* client) { printf("Receive header "); wssl_client_print(client, stdout); printf("\n"); return WSSL_CALLBACK_RESULT_OK; } // same shape for on_connect, on_start_receiving_frames, // on_receive_text/binary/close/ping/pong_frame, and on_disconnect // (which also prints wssl_client_get_disconnect_reason_name(reason))

Each callback logs its own name plus the short client id, so a single connection produces a readable trace: connect, header, start, frames, disconnect with reason.

bool on_tick(wssl_t* wssl) { printf("Tick\n"); #ifdef WSSL_DEBUG wssl_dump(wssl, stdout, 0); #endif return Work; } void on_end(int signal) { Work = false; }

SIGTERM/SIGINT flip the Work flag via plain signal() handlers, and the next tick returns false, which stops wssl_loop(). In WSSL_DEBUG builds each tick also dumps the whole instance.

wssl_server_configuration_t server_configuration = WSSL_SERVER_CONFIGURATION_IPV6_DUAL_STACK; if (arguments_count == 3) // port 6011 + wssl_server_configuration_enable_ssl(cert, key) else // port 6001 plain

Unlike the first three examples there is no config-file mode here: one server only, TLS selected by passing the two file paths. After the loop a final wssl_dump() runs in debug builds.

Example: test examples/test.c

Smallest possible running server: no callbacks at all. Same ports as dump (6001 plain, 6011 with certificate and key).

WSSL_DECLARE(wssl); wssl_server_configuration_t server_configuration = WSSL_SERVER_CONFIGURATION_IPV6_DUAL_STACK; // port 6001, or 6011 + enable_ssl when two file arguments are given WSSL_TRY_CALL(wssl_server_add(&wssl, &server_configuration)); WSSL_TRY_CALL(wssl_loop_init_signals()); WSSL_TRY_CALL(wssl_loop(&wssl)); WSSL_TRY_CALL(wssl_clean(&wssl));

With every callback left at WSSL_CALLBACK_NONE the server still accepts connections and completes handshakes, then silently drops inbound frames. Useful as a loop and TLS smoke test: if this runs, the library core works.

wssl_t

Root library instance. Usually created with WSSL_DECLARE(name) on the stack. Holds global tuning, registered callbacks, the epoll descriptor and the server/client lists.

Created by wssl_server_add(), removed by wssl_server_delete(). The struct stays owned by the library; keep the returned pointer only to delete or dump it.

wssl_client_t

typedef struct wssl_client_t { wssl_server_t* server; struct wssl_t* wssl; wssl_id_t id; int socket_descriptor; char ip[WSSL_IP_SIZE_IN_CHAR]; int port; void* connection_extra_data; wssl_buffer_t input_buffer; wssl_header_t header; // valid after header callbacks wssl_frame_t frame; // current frame while receiving wssl_client_state_e state; wssl_client_disconnect_reason_e disconnect_reason; wssl_mseconds_t last_receive_in_mseconds; // monotonic clock of last received byte /* ... output queue, ssl state ... */ } wssl_client_t;

The callback argument. Read header, ip, port, id freely; never close socket_descriptor or free the struct yourself. Use wssl_client_mark_for_disconnecting() to drop the connection and connection_extra_data for per-connection state.

wssl_header_t struct

typedef struct wssl_header_t { wssl_string_t method; // e.g. "GET" wssl_string_t uri; // request path, usable as room/channel name wssl_string_t version; // e.g. "HTTP/1.1" /* field list + count */ wssl_size_t number_of_fields; } wssl_header_t; typedef struct wssl_header_field_t { wssl_string_t key; wssl_string_t value; /* ... internal link ... */ } wssl_header_field_t;

Filled during the handshake. Look up fields with wssl_header_get_field_value(header, "Sec-WebSocket-Key"); key match is by exact name. Dump with wssl_header_dump() / wssl_header_field_dump().

wssl_frame_t struct

typedef struct wssl_frame_t { bool fin; wssl_octet_t opcode; bool masked; wssl_octet_t length; wssl_octet_t masking_key[4]; wssl_octet_t* payload; wssl_frame_size_t payload_size; bool payload_owned; } wssl_frame_t;

Current inbound frame on client->frame. Opcodes follow RFC 6455 (1 = text, 2 = binary, 8 = close, 9 = ping, 10 = pong). Client frames must be masked; the library enforces it. Inspect with wssl_frame_dump().

typedef struct wssl_string_t { char* data; // not necessarily NUL-terminated wssl_size_t data_length; } wssl_string_t; #define WSSL_MAKE_STRING(what_data, what_data_length) \ ((wssl_string_t){ .data = (what_data), .data_length = (what_data_length) })

wssl_callback_result_e enum

WSSL_CALLBACK_RESULT_OK // continue WSSL_CALLBACK_RESULT_DISCONNECT // clean disconnect of this client WSSL_CALLBACK_RESULT_ERROR // error disconnect of this client

Return type of every frame callback. on_disconnect returns void; on_tick returns bool (true = keep running).

Callbacks

Register each callback with its matching wssl_set_on_*_callback(). Unset callbacks equal WSSL_CALLBACK_NONE and are skipped. They fire in lifecycle order: connect, header, start-of-frames, then one per frame, plus disconnect at the end and tick once per loop pass.

Return values

Every client callback returns wssl_callback_result_e: OK continues normally, DISCONNECT schedules a clean drop (REQUESTED), ERROR schedules an error drop (CALLBACK_ERROR). Two callbacks differ: on_disconnect returns void, on_tick returns bool (true keeps the loop running, false stops it).

Payload lifetime

Frame payload pointers (data) point into the client's input buffer and are valid only while your callback runs; copy them if you need them later. Sending is safe without copying: the send functions serialize the payload into the output queue immediately, so replying with the received pointer in the same call (as echo does) is correct. Text payloads are char* plus length with no NUL terminator assumed; binary, ping and pong payloads are wssl_octet_t* plus length.

on_connect

wssl_callback_result_e on_connect(wssl_client_t* client);

Receives the freshly accepted client: id, ip and port are set, but the HTTP header has not been parsed yet. Use it to attach connection_extra_data or reject early: DISCONNECT / ERROR drop the connection before the handshake is processed.

on_disconnect

void on_disconnect(wssl_client_t* client, wssl_client_disconnect_reason_e disconnect_reason);

Receives the dying client and why it goes away; returns nothing. Use it for cleanup, logging and optional farewell broadcasts like the chat LEAVE message, which is sent only for clean reasons via disconnect_reason_is_not_error.

on_receive_header

wssl_callback_result_e on_receive_header(wssl_client_t* client);

Receives the client with the parsed upgrade header ready in client->header (method, uri, fields). Return OK to let the handshake proceed to the 101 reply; DISCONNECT drops the client as REQUESTED, ERROR as CALLBACK_ERROR, and a malformed header drops it as BAD_HEADER. This is the place to route by uri or check Origin and protocol headers.

on_start_receiving_frames

wssl_callback_result_e on_start_receiving_frames(wssl_client_t* client);

Receives the client right after the 101 handshake reply is queued: from here on the connection speaks WebSocket frames. OK starts frame processing; DISCONNECT / ERROR drop the client. The chat example announces JOIN here.

on_receive_text_frame

wssl_callback_result_e on_receive_text_frame(wssl_client_t* client, char* data, wssl_size_t data_size);

Receives one complete text frame: pointer plus length, no NUL terminator. OK keeps the connection, DISCONNECT / ERROR drop it. The echo example sends the payload straight back with WSSL_MAKE_STRING(data, data_size).

on_receive_binary_frame

wssl_callback_result_e on_receive_binary_frame(wssl_client_t* client, wssl_octet_t* data, wssl_size_t data_size);

Same contract as the text callback, for binary frames (raw octets plus length). Pair it with wssl_client_send_binary for binary echo or relay.

on_receive_close_frame

wssl_callback_result_e on_receive_close_frame(wssl_client_t* client);

Receives the client whose peer asked to close. On OK the library sends the close reply itself and drops the client as REQUESTED; DISCONNECT drops as REQUESTED without the reply, ERROR as CALLBACK_ERROR. Use it for logging and cleanup.

on_receive_ping_frame

wssl_callback_result_e on_receive_ping_frame(wssl_client_t* client, wssl_octet_t* data, wssl_size_t data_size);

Receives one ping with its payload. The library answers with a pong carrying the same payload right after your callback returns (unless the callback scheduled a drop), so you only need this for observation (latency logging, activity tracking).

on_receive_pong_frame

wssl_callback_result_e on_receive_pong_frame(wssl_client_t* client, wssl_octet_t* data, wssl_size_t data_size);

Receives one pong with its payload. Nothing happens automatically; use it to measure round-trip time or confirm the peer is alive.

on_tick

bool on_tick(struct wssl_t* wssl);

Receives the library instance once per loop pass, with no client context (reach state via global_extra_data and clients via for_each). Return true to keep looping, false to stop the loop after this pass. While the loop is idle each pass blocks up to sleep_in_mseconds in epoll_wait, so that value sets the idle tick period; the time example uses 500 ms.

on_timeout

wssl_callback_result_e on_timeout(wssl_client_t* client, wssl_client_state_e state);

Receives a client that sent nothing for timeout_in_mseconds, plus the state it was stuck in. Return OK to forgive it and restart its clock, DISCONNECT / ERROR to drop it like any other callback. With no callback registered the library always drops the client as TIMEOUT. Disabled while the timeout is 0.

on_send_ping_frame

wssl_callback_result_e on_send_ping_frame(wssl_client_t* client);

Asks whether to send this client its periodic empty ping frame. Fires once ping_interval_in_mseconds passed since the last ping; return OK to send it and restart the ping clock, DISCONNECT / ERROR to drop the client. With no callback registered the library sends the ping on its own. Disabled while the interval is 0. The peer answers with a pong, which counts as received data against timeout_in_mseconds — that is how a silent listener proves the connection is alive.

for_each callback

wssl_callback_result_e for_client(wssl_client_t* client, void* local_extra_data);

Not registered on the instance: you pass it to wssl_for_each_client_in_frame_processing_call(), which invokes it once per connected client with your local_extra_data pointer. The same three-way return applies per client (OK continues, DISCONNECT / ERROR schedule that client's drop), and the iteration always visits the remaining clients.

WSSL_DECLARE macro

#define WSSL_DECLARE(what_name) wssl_t what_name = WSSL_INIT_VALUE(what_name)

Declares and initializes a wssl_t with defaults in one line. Equivalent to declaring the variable and calling wssl_init(). Used by all bundled examples.

wssl_init

void wssl_init(wssl_t* wssl);

Initializes an existing wssl_t to defaults (same values as WSSL_INIT_VALUE). Call once before any wssl_set_* or wssl_server_add().

wssl_set_* inline setters

Plain field assignments on wssl_t: each setter writes one field and nothing else. Call them after init and before wssl_loop(); every default they override is listed under default values.

wssl_loop

wssl_result_t wssl_loop(wssl_t* wssl);

Runs the epoll event loop until a signal or on_tick returning false stops it. Returns a wssl_result_t; check with WSSL_TRY_CALL.

wssl_loop_init_signals

wssl_result_t wssl_loop_init_signals(void);

Installs the signal handlers the loop relies on for clean shutdown. Call once before wssl_loop(), as every example does.

wssl_clean

wssl_result_t wssl_clean(wssl_t* wssl);

Releases servers, clients and the epoll descriptor. Call after wssl_loop() returns, even on error paths.

wssl_purge

void wssl_purge(wssl_t* wssl);

Frees disconnected clients without tearing down servers. The loop calls this internally; direct use is rarely needed.

wssl_dump

void wssl_dump(const wssl_t* wssl, FILE* file, wssl_size_t indent_level);

Prints the whole instance (servers plus client lists) for debugging, e.g. wssl_dump(&wssl, stdout, 0).

WSSL_TRY_CALL macro

#define WSSL_TRY_CALL(...) wssl_try_call_test((__VA_ARGS__), __FILE__, __LINE__, __func__)

Checks a wssl_result_t; on failure prints file, line, function and the result, then aborts. Standard error handling in the examples.

void wssl_try_call_test(wssl_result_t result, const char* file_name, const unsigned int line_number, const char* function_name);

The function behind the macro: prints the result with its call context and aborts. Never call it directly; the macro fills file_name, line_number and function_name from the call site.

wssl_server_add

wssl_result_t wssl_server_add(wssl_t* wssl, const wssl_server_configuration_t* configuration);

Opens, binds and listens on one address from a filled configuration struct. Copy semantics: the struct can be a stack temporary. Call once per listen address.

wssl_server_delete

wssl_result_t wssl_server_delete(wssl_server_t* server);

Stops and removes a server previously added. Clients on it are disconnected.

wssl_server_configuration_set_*

void wssl_server_configuration_set_ip(wssl_server_configuration_t*, const char*); void wssl_server_configuration_set_port(wssl_server_configuration_t*, int); void wssl_server_configuration_set_ipv6(wssl_server_configuration_t*, bool); void wssl_server_configuration_set_ipv6_dual_stack(wssl_server_configuration_t*, bool); void wssl_server_configuration_set_ssl(wssl_server_configuration_t*, bool); void wssl_server_configuration_set_certificate_files(wssl_server_configuration_t*, const char* certificate_file, const char* private_key_file); void wssl_server_configuration_enable_ssl(wssl_server_configuration_t*, const char* certificate_file, const char* private_key_file);

Plain field assignments with no result to check and no validation; the string helpers copy into fixed-size buffers. The single-field setters are generated by a macro, the certificate helpers are plain functions. enable_ssl stores both file paths and flips ssl on; set_certificate_files stores the paths. Missing files surface later as WSSL_RESULT_CODE_ERROR_SSL.

wssl_server_enable_ssl

wssl_result_t wssl_server_enable_ssl(wssl_server_t* server);

Loads the certificate and key from server->configuration into the live server. Use when the configuration was changed after wssl_server_add().

wssl_server_dump

void wssl_server_dump(const wssl_server_t* server, FILE* file, wssl_size_t indent_level);

Prints one server and its client list. Useful next to wssl_client_dump() when tracing connection issues.

wssl_client_send_text

wssl_result_t wssl_client_send_text(wssl_client_t* client, const char* text);

Sends a text frame from a NUL-terminated C string. Returns WSSL_RESULT_CODE_ERROR_NO_SPACE when the per-client output queue is full.

wssl_client_send_string

wssl_result_t wssl_client_send_string(wssl_client_t* client, const wssl_string_t* string);

Sends a text frame from a length-counted string. The echo example forwards the received payload with WSSL_MAKE_STRING(data, data_size) without assuming termination.

wssl_client_send_binary

wssl_result_t wssl_client_send_binary(wssl_client_t* client, wssl_octet_t* data, wssl_size_t data_size);

Sends a binary frame from raw octets. Pair with on_receive_binary_frame_callback on the receiving side.

wssl_client_send_ping

wssl_result_t wssl_client_send_ping(wssl_client_t* client);

Sends an empty ping frame right away, regardless of ping_interval_in_mseconds. Never fires on_send_ping_frame — that callback belongs to the periodic gate only — but it does restart the periodic ping clock.

wssl_for_each_client_in_frame_processing_call

void wssl_for_each_client_in_frame_processing_call(wssl_t* wssl, wssl_for_each_client_callback_f* callback, void* local_extra_data);

Calls callback(client, local_extra_data) for every client that finished the handshake. The chat and time examples broadcast this way. Returning WSSL_CALLBACK_RESULT_OK from the callback continues the iteration.

wssl_client_mark_for_disconnecting

void wssl_client_mark_for_disconnecting(wssl_client_t* client, wssl_client_disconnect_reason_e disconnect_reason);

Schedules a disconnect; the loop performs it after the current callback returns. Prefer this over closing the socket. Use WSSL_CLIENT_DISCONNECT_REASON_REQUESTED for application-initiated drops.

wssl_client_reset_timeout

void wssl_client_reset_timeout(wssl_client_t* client);

Restarts the client's silence clock from now, as if it had just sent data. Call from any client callback to keep a quiet but live connection past timeout_in_mseconds; returning OK from on_timeout does the same without an explicit call. Compiling against out/wssl.h needs _POSIX_C_SOURCE defined, see Build and link.

wssl_header_get_field_value

wssl_string_t* wssl_header_get_field_value(const wssl_header_t* header, const char* key);

Returns the value of a header field, or NULL when absent. Returned pointer points into the header; do not free it. Useful for routing on uri or checking Origin / protocol headers in on_receive_header.

Useful macros

Shortcuts from out/wssl.h that remove boilerplate. Already covered elsewhere: WSSL_DECLARE, WSSL_TRY_CALL, the WSSL_DEFAULT_* values and the WSSL_SERVER_CONFIGURATION_* presets.

Direction annotations

#define _WSSL_IN_ #define _WSSL_OUT_ #define _WSSL_MODIFY_

Empty markers in front of pointer parameters: _WSSL_IN_ is read-only input, _WSSL_OUT_ is written by the call, _WSSL_MODIFY_ is read and written. Use them in your own callback prototypes for consistency with the library style.

Strings without copying

#define WSSL_MAKE_STRING(what_data, what_data_length) \ ((wssl_string_t){ .data = (what_data), .data_length = (what_data_length) })

Builds a length-counted wssl_string_t on the spot, no allocation and no NUL terminator required. The echo example forwards the received frame this way: wssl_client_send_string(client, &WSSL_MAKE_STRING(data, data_size)). The pointer must stay valid until the call returns.

Sentinels and sizes

#define WSSL_NULL NULL #define WSSL_NO_DESCRIPTOR (-1) #define WSSL_CALLBACK_NONE WSSL_NULL #define WSSL_IP_SIZE_IN_CHAR 64 #define WSSL_FILE_PATH_SIZE_IN_CHAR 4096 #define WSSL_FRAME_MASKING_KEY_SIZE 4

WSSL_NULL is the default for every unset callback (WSSL_CALLBACK_NONE) and for extra-data pointers. WSSL_NO_DESCRIPTOR is the initial epoll_descriptor value. The size macros are the array capacities inside wssl_server_configuration_t and wssl_client_t; size your own buffers with them instead of hardcoding 64 / 4096.

Printf format macros

#define WSSL_PRINT_OCTET "02" PRIx8 // wssl_octet_t -> two hex digits #define WSSL_PRINT_SIZE "zu" // wssl_size_t #define WSSL_PRINT_SSIZE "zd" // wssl_ssize_t #define WSSL_PRINT_MSECONDS PRIu64 // wssl_mseconds_t #define WSSL_PRINT_ID_PREFIX PRIu32 // wssl_id_prefix_t #define WSSL_PRINT_ID_SUFFIX PRIu32 // wssl_id_suffix_t #define WSSL_PRINT_FRAME_SIZE PRIu64 // wssl_frame_size_t

Concatenate with the % marker: printf("%" WSSL_PRINT_SIZE, size). The chat example prints ids as "%" WSSL_PRINT_ID_SUFFIX. Using these keeps format strings correct on every platform instead of guessing %d / %lu.

Assertions and init values

#define WSSL_ASSERT(what_expression) // aborts with file:line in WSSL_DEBUG builds, // compiles to ((void)0) otherwise void wssl_assert_fail(const char* expression, const char* file_name, const unsigned int line_number, const char* function_name); #define WSSL_ID_INIT_VALUE // { .prefix = 0, .suffix = 0 } #define WSSL_CHAIN_ROOT_INIT_VALUE(what_name) #define WSSL_CHAIN_LINK_INIT_VALUE

WSSL_ASSERT guards invariants during development at zero cost in release builds. The init-value macros prefill wssl_id_t and internal list links; you rarely need them directly because wssl_init() applies all of them, but they are there when a struct is built by hand.

Client extra data

void* wssl_get_global_extra_data(const wssl_t* wssl); void wssl_set_global_extra_data(wssl_t* wssl, void* global_extra_data); wssl_t* wssl_client_get_wssl(const wssl_client_t* client); void* wssl_client_get_global_extra_data(const wssl_client_t* client); void wssl_client_set_connection_extra_data(wssl_client_t* client, void* connection_extra_data); void* wssl_client_get_connection_extra_data(const wssl_client_t* client);

Two-level state: one global pointer per wssl_t, one pointer per connection. From a client callback, wssl_client_get_wssl(client) reaches the root, and wssl_client_get_global_extra_data(client) is the shortcut to the shared state. Returns: getters give back the stored pointer (NULL when never set); setters return nothing.

Read-only state predicates for branching and assertions. Each returns bool (true when the client is in the named situation; every predicate has its _not_ negation). Frame callbacks normally see is_in_frame_processing == true.

Client name helpers

const char* wssl_client_get_state_name(wssl_client_state_e state); const char* wssl_client_get_disconnect_reason_name(wssl_client_disconnect_reason_e reason); bool wssl_client_disconnect_reason_is_error(wssl_client_disconnect_reason_e reason); bool wssl_client_disconnect_reason_is_not_error(wssl_client_disconnect_reason_e reason); void wssl_client_print(const wssl_client_t* client, FILE* file); void wssl_client_dump(const wssl_client_t* client, FILE* file, wssl_size_t indent_level);

Logging and disconnect handling. Returns: name getters give const char* labels, the is_error variants give bool, print and dump give nothing. The chat example uses is_not_error to broadcast LEAVE only on clean exits. wssl_client_print() writes the short {prefix,suffix} [ip]:port -> [ip]:port form.

Dump helpers

void wssl_buffer_dump(const wssl_buffer_t*, FILE*, wssl_size_t indent_level); void wssl_frame_dump(const wssl_frame_t*, FILE*, wssl_size_t indent_level); void wssl_header_dump(const wssl_header_t*, FILE*, wssl_size_t indent_level); void wssl_header_field_dump(const wssl_header_field_t*, FILE*, wssl_size_t indent_level);

Result helpers

bool wssl_result_is_ok(wssl_result_t result); bool wssl_result_is_not_ok(wssl_result_t result); const char* wssl_result_get_code_name(wssl_result_t result); void wssl_result_print(wssl_result_t result, FILE* file);

Every fallible call returns wssl_result_t. Returns: is_ok / is_not_ok give bool, get_code_name gives the const char* label, print gives nothing. Branch on is_ok, log with result_print, and let WSSL_TRY_CALL abort with context in examples and tools.

Id helpers

void wssl_id_init(wssl_id_t* id); void wssl_id_set_prefix(wssl_id_t* id, const wssl_id_prefix_t prefix); void wssl_id_set_suffix(wssl_id_t* id, const wssl_id_suffix_t suffix); bool wssl_id_is_equal(const wssl_id_t* id_1, const wssl_id_t* id_2); bool wssl_id_is_not_equal(const wssl_id_t* id_1, const wssl_id_t* id_2); void wssl_id_print(const wssl_id_t* id, FILE* file);

Create, compare and print wssl_id_t values. wssl_id_init zeroes both halves; the setters seed the start value used for the next connection (same effect as wssl_set_id_prefix / wssl_set_id_suffix on the instance). wssl_id_print writes the {prefix,suffix} form. Returns: init, setters and print give nothing; the two comparisons give bool.

Chain helpers

void wssl_client_chain_root_init(wssl_client_chain_t* root); // root points to itself void wssl_client_chain_link_init(wssl_client_chain_t* link); // link detached (NULL, NULL)

The same pair exists for wssl_server_chain_t, wssl_chunk_chain_t and wssl_header_field_chain_t, with the list type swapped in place of wssl_client_chain_t.

List plumbing for the server, output-chunk, header-field and client lists. wssl_init() initializes every root; links are managed by add/delete calls. Both return nothing (void); direct use is not needed in application code.
